# Ativação Inteligente do NexOffice

## Objetivo

Fazer cada empresa começar pelo que traz valor operacional real para ela. A melhoria da base de dados é consequência do uso útil do produto, não o objetivo apresentado ao cliente.

## Princípios

- no máximo três próximos movimentos por vez;
- recomendações adaptadas ao setor, modelo de receita e uso já observado;
- nada de checklist genérico;
- um passo concluído desaparece automaticamente da lista;
- cada recomendação explica o benefício para a gestão antes do benefício para a inteligência;
- nenhuma recomendação habilita ação financeira externa;
- o plano não é score de crédito.

## Áreas orientadas

- Perfil inteligente: contexto do negócio;
- CRM: clientes e oportunidades;
- Financeiro: caixa, recebíveis e recorrência;
- Agenda e Tarefas: ritmo operacional;
- Documentos: negócios dependentes de contratos;
- Trajetória: indicadores específicos do setor que ainda não podem ser calculados automaticamente.

## Sequência

Operação útil → adoção do módulo certo → dados mais completos → leitura melhor → recomendações mais relevantes.
